Cómo funciona

Una puerta de cierre: el agente puede pedir terminar, pero solo el código concede. Nada corre dentro del modelo.

1
El agente dice «hecho»
Claude Code o Codex intentan terminar el turno. Eso dispara su hook Stop, que llama a rompelo hook <agente>.
2
rompelo lee el contrato
.rompelo/task.json dice qué checks son obligatorios, qué rutas puede tocar la tarea y si cruza una junta con otro sistema.
3
Y compara con la evidencia
Cada check tiene que haber corrido sobre este contenido del árbol, con salida real, y el cruce real tiene que ser posterior al último cambio.
Falta algo → BLOQUEO
El agente recibe la lista exacta de motivos y sigue trabajando. Tres veces por tarea; después avisa al usuario y suelta.
Todo cumplido → silencio
El turno termina. Ningún mensaje: la ausencia de bloqueo es la única forma de «hecho» que existe.
Los comandos nunca vienen del repositorio: el contrato solo lleva ids y los comandos viven en un registro tuyo, ejecutados sin shell. Un repo que no está en tu allowlist no engancha nada.
