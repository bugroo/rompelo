A green you have never seen red is not information

Every rompelo condition is accepted only after this cycle, and the test battery repeats it on every change: 60 cases.

1 · Start from green
A good task with a complete contract, and the hook lets it stop. Without this, the red that follows says nothing: it may have been broken already.
2 · Confirmed mutation → red
The contract is broken on purpose, and it is confirmed that the mutation happened and creates the fault being hunted. Then the hook must block with that exact reason.
3 · Undone → green again
The mutation is removed and the hook goes silent again. A guard that always shouts gets switched off, and then it protects nothing.
The same is demanded of the user's checks: a command that exits 0 without producing output does not count, and the next module asks every check for a positive control, a known-bad input it must detect before its green is worth anything.
