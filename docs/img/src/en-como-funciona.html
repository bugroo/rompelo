How it works

A completion gate: the agent can ask to finish, but only code can grant it. Nothing runs inside the model.

1
The agent says “done”
Claude Code or Codex try to end the turn. That fires their Stop hook, which calls rompelo hook <agent>.
2
rompelo reads the contract
.rompelo/task.json says which checks are required, which paths the task may touch, and whether it crosses a boundary with another system.
3
And compares it with the evidence
Every check must have run on this working-tree content, with real output, and the real crossing must be later than the last change.
Something is missing → BLOCK
The agent gets the exact list of reasons and keeps working. Three times per task; then it warns the user and lets go.
Everything met → silence
The turn ends. No message: the absence of a block is the only “done” there is.
Commands never come from the repository: the contract only carries ids, and the commands live in a registry you own, executed without a shell. A repo outside your allowlist hooks nothing.
